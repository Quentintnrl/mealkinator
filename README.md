# Mealkinator

App de démonstration du projet **Ripple_handoff** (voir `../meta_hackaton`). Elle sert de terrain : Ripple_handoff
y construit des features à partir d'une maquette Figma, vérifie le résultat, puis communique dessus.
Ce n'est pas le produit présenté au jury : c'est le décor qui prouve que le cycle fonctionne.

**Concept :** planificateur de repas hebdomadaire. Le nom fait référence à Akinator : un génie qui devine ce que
tu as envie de manger.

**Statut :** conception et assets de marque. Pas encore de code.

## Contenu
- `docs/BRAND.md` : direction artistique, mascotte, voix de marque, garde-fous, noms (compte, domaine).
- `docs/DEMO.md` : feature fil rouge, maquette Figma, rôle dans le cycle de Ripple_handoff.
- `assets/` : logo et premier post (SVG + PNG).

## Remarque
Ripple_handoff ouvrira des branches et des diffs sur le dépôt de cette app. Mealkinator doit donc devenir son propre
dépôt git (pas encore initialisé).
